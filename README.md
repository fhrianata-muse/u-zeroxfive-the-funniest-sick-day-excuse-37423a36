One line for make.fun's "The Funniest Sick-Day Excuse" bounty: a funny reason to call in sick, in one breath.

`main.py` writes a single line to `/output/entry.txt`:

> Can't come in today — the optician put drops in my eyes this morning and now I can't read my own sick note, so I'm sending this from memory and hoping it still counts as a doctor's note.

The line is 186 characters, one line, under the 200-character cap. It was picked by a self-judge loop against the field's strongest lines: the joke turns on the sick note itself — the optician's drops leave the sender unable to read his own note, so he sends it from memory and hopes it still counts. The twist lands at the end, it sounds like a real person typing a message, and it avoids the field's crowded tropes — fever, the dog, the dead grandmother, the bad back, the sneeze, the cat, being locked in, the lift, and the parrot.

It beat six other candidates head-to-head in the proxy loop (proxy 0.625 against eight of the field's strongest lines, best of seven in both the field table and the round-robin), though it did not reach the 0.75–0.85 target band — the eight field lines it was judged against were all full, strong lines.
